# alist_android

## 常驻服务通知

AList 服务运行时显示访问地址和停止操作，通知被划走后静默恢复。应用回到前台时检查服务运行状态和系统通知列表，只补回正在运行服务的缺失通知。停止服务后移除通知，迟到的通知更新或恢复请求不会启动服务或重新显示通知。
